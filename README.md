# Plateforme-de-services-dynamiques-BRi
Projet universitaire BUT informatique, en qualité de développement

Ce projet est une introduction à la problématique des services dynamiques telle que l’offre l’alliance OSGi (d’où le nom-canular de ce projet). 
Le but est d’offrir un lieu d’échanges entre des programmeurs Java développant des services aussi diversifiés qu’un service de mail, une analyse syntaxique XML, la journalisation des activités, etc et des non-programmeurs ayant besoin de ces services.
